# Architecture

项目包含 Agent 工作流层和确定性验证层。它们共享来源标识、候选版本和计算输入，但承担不同职责。

Agent 工作流层读取实际材料，明确研究问题、假设、终点、对照和可接受参数，整理资源信息并解释方案取舍。证据定位和研究假设需要在这一层由实际阅读支撑。

确定性验证层读取已经规范化的 JSON。`solve` 枚举有限参数组合，对按顺序声明的派生表达式进行 Decimal 计算，检查所有硬约束，并按声明的目标顺序比较可行点。每个点的结果保存在 CSV，汇总与最优点保存在 JSON。

`schedule` 对显式时间区间和资源需求进行审核。它检查任务依赖、预约覆盖、事件区间内的资源容量以及最终截止时间，不搜索所有排期顺序。

表达式通过受限 AST 遍历处理，允许的运算与函数是显式集合。工具不会调用 Python eval，也不会执行模型中的属性访问、导入或任意函数。CLI 使用 50 位有效十进制数字，非终止除法在该精度下舍入。

结果的有效范围由输入模型决定。来源引用存在不代表来源内容真实，公式通过不代表单位正确，约束全部通过也不代表实验具有科学效力。交付时应同时保留来源映射、规范化输入、计算结果、科学解释和未确认事项。

目录结构允许直接作为 Agent Skill 使用，也允许研究者只运行命令行工具。运行时与测试均使用 Python 标准库；CI 按多个 Python 版本重复相同的回归与示例命令。
